# ffmpegVideoConvert 🎬

一个基于 **FFmpeg** 的批量视频处理工具，提供简洁可视化界面，支持多文件选择、进度显示、任务取消，并拓展了 **合并/拆分/压缩** 等场景。

---

## ✨ 功能清单

- **五种处理模式**
  - **保全画质**（quality）：接近视觉无损（H.264，CRF≈18），支持 **硬件加速**（NVENC/QSV/AMF）。
  - **优先压缩**（size）：更小体积（H.264，CRF≈26，自动限制最大分辨率 1080p），支持 **硬件加速**。
  - **仅提取音频**（audio）：输出 `.m4a`（AAC 128k）。
  - **视频合并**（merge）：选择多个视频，**可视化调整拼接顺序**，一键合并。
  - **视频拆分**（split）：对单个视频输入多个时间点，自动切成多段；提供 **三档编码策略**：
    1) **无损**：H.264 lossless（CRF 0），严格不降质；
    2) **视觉无损**：H.264（CRF 18），体积友好；
    3) **硬件加速**：H.264（NVENC/QSV/AMF），接近视觉无损且更快；
    > 另提供 **H.265 压缩**（libx265，CRF 23）选项，可在相近画质下进一步减小体积。

- **批量/多段处理**：常规转码可一次导入多个文件；拆分模式自动生成多段输出。
- **输出目录自定义**：所有结果统一保存到用户指定文件夹；自动避免重名覆盖。
- **实时进度可视化**
  - 当前文件：已处理时长 / 总时长、处理速度（如 10.5x）。
  - 总体进度：已完成数量 / 总数量。
  - 总用时：任务运行时间实时刷新。
- **任务控制**
  - 随时取消：立即终止 FFmpeg 进程。
  - 任务完成：弹窗提示，进度窗按钮切换为“关闭”。
- **环境自检**：启动时检查 `ffmpeg`、`ffprobe` 是否可用，缺失时提示安装。
- **对话框体验优化**：关键弹窗（顺序调整、参数选择等）**强制置顶并居中**，避免被遮挡。
- **后台静默运行**（Windows）：处理时不弹黑色命令行窗口。

## 📥 输入与 📤 输出

- **输入格式**：常见视频（`.mp4 .mov .mkv .avi .flv .wmv .m4v .ts .webm`）
- **输出命名规则**（例）
  - 保全画质（quality） → `原文件名_hq.mp4`
  - 优先压缩（size） → `原文件名_small.mp4`
  - 仅音频（audio） → `原文件名.m4a`
  - 视频合并（merge） → 默认 `第一个文件名_merged.原扩展名`
  - 视频拆分（split） → `原文件名_partXX.原扩展名`
- **重名处理**：自动在结尾追加 `_1/_2/...` 避免覆盖。

## 🚀 使用说明（典型流程）

1. 运行应用，选择处理模式。
2. **常规转码（quality / size）**
   - 选择待处理文件（可多选）。
   - 选择 **编码器**：CPU（x264）或 **硬件加速**（NVENC/QSV/AMF）。
   - （可选）程序会按模式自动设置 CRF / 预设与分辨率上限：
     - 质量优先：≈CRF 18（视觉无损倾向），`-movflags +faststart` 便于网页播放。
     - 体积优先：≈CRF 26 + 最大 1080p。
   - 选择输出目录 → 开始处理。
3. **视频合并（merge）**
   - 选择 ≥2 个视频；
   - 在 **“调整拼接顺序”** 弹窗中拖动/按钮调整，点击确定；
   - 选择输出目录与文件名，开始合并。
4. **视频拆分（split）**
   - 选择 1 个视频文件；
   - 输入多个时间戳（以逗号、空格或换行分隔，支持 `秒` 或 `HH:MM:SS[.ms]`）；
   - 选择 **拆分编码策略**：
     - 无损（H.264 CRF 0）/ 视觉无损（H.264 CRF 18）/ 硬件加速（H.264）/ **H.265 压缩（libx265 CRF 23）**；
   - 选择输出目录，开始拆分。
5. 处理过程中可查看 **当前进度**、**总体进度**、**处理速度**，并可随时取消。

> ✍️ 提示  
> - 若你遇到音画不同步：拆分时使用 **无损** 或 **视觉无损** 档（`-ss/-t` 放在输入后，帧级精确），避免 `-c copy` 导致的关键帧切点偏移。  
> - 若你希望 **更小体积**：选择 **H.265**；在有 NVIDIA/Intel/AMD 的机器上，优先使用 **硬件加速** 档可显著提速。

## 💻 运行条件

1. **操作系统**：Windows 10 / 11  
2. **依赖**：需预先安装 [FFmpeg](https://ffmpeg.org/download.html) 并加入系统 `PATH`  
   ```bash
   ffmpeg -version
   ffprobe -version

能输出版本号即配置成功。
3. 硬件：多核 CPU 建议；如需硬件加速，需具备并正确安装对应显卡驱动（NVIDIA/Intel/AMD）。
